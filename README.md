# Portfolio de Lucas Ribet

Portfolio personnel réalisé en HTML, CSS et JavaScript natifs. Il présente
mon parcours de Technicien Support Utilisateurs, mes compétences Microsoft 365
et quelques projets personnels.

## Prévisualisation

Ouvrir `index.html` dans un navigateur. Aucune installation ni compilation
n'est nécessaire.

## Pages

- `index.html` : présentation, compétences, projets et contact.
- `scanner-pc.html` : informations accessibles depuis les API Web du navigateur.
- `compatibilite-navigateur.html` : disponibilité de quelques API Web.
- `cv.html` : aperçu et téléchargement du CV PDF.
